Install in three steps

1

Open the download.

2

Drag it to Applications.

Drag the Mahfouz icon onto the Applications folder in the window that opens.

3

Open Mahfouz.

Find it in Applications or Launchpad, then add your first vault.

Updates

New versions install themselves.

When a release is out, a banner in Mahfouz says so. Choose Install and it updates in place. No new download, no dragging to Applications again.

A new version of Mahfouz is ready to install. Install

Prefer Homebrew?

Install from the Mahfouz tap instead. You get the same app.

brew install --cask mahfouz-app/tap/mahfouz

Update from the banner in the app, or with brew upgrade --cask mahfouz.
