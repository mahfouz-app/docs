Adds **PDF** to the Export dialog: a note's menu → **Export…** (or
<kbd>Cmd/Ctrl</kbd><kbd>Shift</kbd><kbd>E</kbd>). The note renders as a deck,
styled by the vault's slides template, and **Save…** asks where to put the
file once it's ready.

- It renders with [Slidev presentations](/plugins/mahfouz/slidev/), which
  installs with it.
- Progress shows on the notification bell.

See [Presenting notes as slides](/guide/slides/) for templates.
