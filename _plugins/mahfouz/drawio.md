```` ```drawio ```` blocks render as diagrams. **Edit** on a diagram, or
inserting one from the toolbar's **Embed** menu, opens it in a draw.io tab.
Changes save back into the note as you go. In Mahfouz 0.20.0 and later, a
click on a diagram opens it full size in the viewer, and a click on an
empty one opens the draw.io tab.

- It installs the full draw.io editor, around 150 MB, so the first install
  takes a while, especially in a browser.
- Published pages show diagrams as images.
