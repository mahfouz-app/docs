```` ```drawio ```` blocks render as diagrams. Click one, or insert one from
the toolbar's **Embed** menu, to edit it in a draw.io tab. Changes save back
into the note as you go.

In 0.20.0 and later, a click on a diagram opens it full size in the viewer,
and its **Edit** opens the draw.io tab. A click on an empty diagram opens
the tab straight away. {% include since.html v="0.20.0" %}

- It installs the full draw.io editor, around 150 MB, so the first install
  takes a while, especially in a browser.
- Published pages show diagrams as images.
