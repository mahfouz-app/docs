Submit a plugin

Publish your plugin in a registry: any git repository with the registry layout. Then open a pull request on mahfouz-app/docs that adds a file for it at _plugins/<registry>/<plugin id>.md, such as _plugins/acme/kanban-export.md. It becomes the plugin's page here: 

---
name: Kanban export
description: Export a task board as CSV.
category: Export             # one of the categories above
author: Acme Labs
author_url: https://github.com/acme
platforms: [macos, linux, windows, web]
requires: 0.12.0             # the first Mahfouz version it works with
source: https://github.com/acme/mahfouz-plugins/tree/main/plugins/kanban-export
---

What the plugin does and how to use it, in Markdown.

If your registry isn't listed yet, add it to _data/plugin_registries.yml in the same pull request. Being listed here isn't a security review. Every listing follows the plugin registry policy.
