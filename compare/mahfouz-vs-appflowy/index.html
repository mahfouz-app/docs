Mahfouz vs AppFlowy

Mahfouz vs AppFlowy

AppFlowy is open source and runs on your desktop, but your notes live in its own database, and syncing or sharing them means AppFlowy Cloud or a server you deploy and license yourself. Mahfouz keeps plain Markdown files and syncs them through any Git remote you already have, or none.

Feature comparison

Compare AppFlowy Mahfouz
File format & ownership Open source, but notes live in a local database the app manages, not Markdown files you can browse or edit elsewhere. Plain .md files in a folder you choose. Open, edit, or grep them with any tool.
Where it runs On your desktop with no account. Sync and collaboration need AppFlowy Cloud or a self-hosted server (Docker). On your computer, or in your browser at web.mahfouz.app. No account needed, and Mahfouz has no cloud of its own and keeps no copy of your notes.
Version history Page history: 7 days on the free cloud plan, 90 on Pro. Full history in a real Git repo, kept as long as you keep it, not a vendor's retention window.
Offline use The desktop app works offline; sync and collaboration need the server. Fully local-first. Works offline by default; there's no "download for offline" step.
Sync & collaboration Real-time, through AppFlowy Cloud or your own server. No file-based sync. Built in, through any Git remote you choose. Everyone works from their own full copy, and track changes lets people suggest edits. There's no live multiplayer editing.
In the browser Yes, with an AppFlowy Cloud or self-hosted account. The web app at web.mahfouz.app opens a folder on your computer or a GitHub repository, with no copy kept on Mahfouz's servers.
AI agents AppFlowy AI is built in, and local AI through Ollama is free. No official MCP server yet; community ones exist. Agents can read the files directly, and Claude Code, Codex, and other MCP clients can connect to Mahfouz, with per-vault access and edits that wait for your approval.
Databases Grid, board, and calendar views. Built in. Each row is a note, with table, board, gallery, and calendar views.
Tasks To-do lists, plus task boards with due dates and reminders. Turn a checklist item into a task with a due date, an assignee, and a reminder, and see every task in a list or on a board.
Presentations No built-in presentation mode. Present any note as slides styled by a vault-wide template, and export the deck to PDF or PowerPoint (desktop, Slidev plugin).
Publishing Publish pages to the web through AppFlowy Cloud; self-hosted servers need extra setup. Publish a note as a public page at a link you share, and keep it in step with the note.
Track changes No suggestion mode; collaborators edit the page directly. Built in. Suggest edits instead of making them, then accept or reject each one, with comments alongside.
Platforms macOS, Windows, Linux, iOS, Android, and the web. macOS and the web today. Windows and Linux are coming soon.
Price Cloud is free for one person with 100 MB of storage; Pro is $16/member/month billed annually ($20 monthly). Self-hosting is free for one user and 3 guests; teams pay $10/seat/month. Free. No seats. The only cost is whatever Git hosting you choose, if any.
Data export / lock-in Pages export one at a time to Markdown or PDF, and databases to CSV, from an app-managed database. Nothing to unlock: notes are files. Export a note and its children to Markdown with their attachments, or to PDF.

AppFlowy pricing as published on appflowy.com in October 2026; check their pricing page for current figures.

Questions

AppFlowy, answered.

AppFlowy is open source. Doesn't that protect me from lock-in?

Open source code doesn't make your notes portable. AppFlowy keeps notes in an app-managed database, exported a page at a time, and its self-hosted sync server now ships under a commercial licence. Mahfouz keeps your notes open where it matters: they're plain Markdown files in a Git repository, readable and editable without Mahfouz, and there's no server to run at all.

If I self-host AppFlowy, is that the same as Mahfouz's local-first model?

No. Self-hosting AppFlowy still means standing up, updating, and paying for a server you're responsible for, and a team needs a paid licence. Mahfouz has nothing to host, on your infrastructure or anyone else's; your vault is just a folder that happens to be a Git repo.

Does Mahfouz support real-time collaboration like AppFlowy?

Not in the live, multiplayer sense. Collaboration works the way Git collaboration always has: everyone has a full copy, and changes merge through commits. No server has to stay online for it to work.
