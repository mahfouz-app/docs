# Heading links

Links to a heading. In Preview a heading link reads Note › Heading; open one to land on the heading.

- Another note's heading: [[Numbered headings#Part two]]
- With its own text: [[Numbered headings#Scope|what's in scope]]
- A heading in this note: [[#Try them]]
- A Markdown link by anchor: [the plan](numbered_headings.md#plan)
- A Markdown link in this note: [the Try them section](#try-them)
- A heading that doesn't exist: [[Numbered headings#No such heading]] opens the note at the top with a "Heading not found" notice.

Type `[[Numbered headings#` to list that note's headings, or `[[#` for this note's.

## Try them

Hover over this heading, or put the cursor on its line, and click the link icon at its end to copy `[[Heading links#Try them]]`.
