# Database view with a column before Title

An embed of the Reading list's Status first view, whose order puts Status before Title. In Preview the embed's table shows Status as its first column, and on a published page or an export the snapshot table starts with Status too. Title's cell is still each row's header.

```database-view
source: "[[Reading list]]"
view: Status first
```
