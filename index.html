Open. No lock-in. Ever.

Notes that stay yours.

Mahfouz keeps your notes as plain Markdown files in a folder on your computer: nothing proprietary, nothing to export. Open and edit them with any editor, script, or AI agent, and let Git look after their history.

A familiar tool, built in

Real history. Real collaboration.

Mahfouz uses Git to record edits, show past versions, and restore a note without erasing what came before. Because Git is distributed, your vault isn’t tied to one server. Push it to GitHub, self-host it, or hand a copy to a collaborator, and everyone keeps working from their own full copy of the history.

Everyday edits
Saved as Git commits automatically.
Past versions
Browse a note’s history and restore a version.
Remote sync
Use your existing Git setup and credentials.
Collaboration
Share a vault the way you’d share any Git repo, with no server Mahfouz controls.

Write your own.

A plugin is a folder with a plugin.json manifest and a JavaScript module. It can add embeds, editor tabs, toolbar buttons, commands, export formats, and importers. Share it from any Git repository: anyone can add that repository as a registry and install your plugins from it.

How Mahfouz stacks up

Mahfouz vs the rest.

Every one of these tools can hold your notes. The difference is what happens to them afterward: whether they stay plain files you own, or become records in someone else's database on someone else's server.
