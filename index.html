Notes that stay yours.

Mahfouz keeps your notes as plain Markdown files in a folder on your computer — nothing proprietary, nothing to export. Open and edit them with any editor, script, or AI agent, and let Git look after their history.

A little more room to think

Your notes, without the lock-in.

Write in Markdown, follow ideas across your vault, and keep every note in a format that will still make sense years from now — one that any editor, tool, or agent can open without asking Mahfouz first.

A home for every thought.

Keep notes as ordinary Markdown files in folders you choose. Open several vaults, shape notes into a tree, and pin the ones you return to.

  • Nested notes and folders
  • Multiple vaults and tabs
  • Bookmarks and tags
  • Every file readable and editable outside Mahfouz — no export step

Move through ideas, not folders.

Link notes by title, see what points back, and search every open vault. A live outline and page preview help you find your place in longer notes.

  • Wikilinks and backlinks
  • Fast vault-wide search
  • Outline and page preview

Every change has a way back.

Git records edits as you work. Browse a note’s history, restore an earlier version, recover deleted notes from Trash, or sync your vault with a remote.

  • Automatic commits
  • Per-note history
  • Remote sync and restore

When a note wants to become more

Write it once. Present it when you’re ready.

Use the formatting toolbar, tables, checklists, and media as you write. Turn a note into a slide deck with the presentations plugin, then export a PDF when you need a copy to share.

A familiar tool, built in

Real history. Real collaboration.

Mahfouz uses Git to record edits, show past versions, and restore a note without erasing what came before. Because Git is distributed, your vault isn’t tied to one server — push it to GitHub, self-host it, or hand a copy to a collaborator, and everyone keeps working from their own full copy of the history.

Past versions

Collaboration
Share a vault the way you’d share any Git repo — no server Mahfouz controls.
