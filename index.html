More than notes

Build it all on Markdown.

People, tags, tasks and databases aren't hidden in an app database. Each one is a line, a field or a folder in your notes, so you can change it in any editor and Mahfouz picks it up.

People

Everyone you work with.

A person is a note with a handle. Mention @ada anywhere, and their page gathers the tasks and notes that mention them.

Ada Lovelace.md
---
person: ada
email?: ada@engine.co
company?: Analytical Engines
---

Tasks

Due dates, right in the line.

A checkbox, an assignee and a date. The Tasks view collects them from every vault, and reminds you when they're due.

Reading list.md
- [ ] Finish Dune @ada // 2026-11-04
- [/] Notes on chapter 3 // 2026-11-02
- [x] Order the next book

Tags

Tag as you write.

Type a #tag in a sentence or list tags in the frontmatter. Search, filter and map your vault by them.

Cairo Journal.md
---
tags: [travel, cairo]
---
The old stone holds the warmth. #field-notes

Databases

Tables, boards and calendars.

A database is a note whose child notes are its rows. Each cell is a row's own frontmatter, and the views are YAML in the note.

Books/
Books.md              database: true
Dune.md               status: Reading
The Dispossessed.md   status: Done

Private by default

Your notes go nowhere you didn't send them.

Mahfouz has no cloud of its own, keeps no copy of your notes, and doesn't hand them to an AI. Your notes leave your computer only when you choose where: a Git remote you pick, or an AI agent you set up.

Cloud

No Mahfouz cloud.

A vault is a folder and a Git repository on your disk. To sync, push it to a private GitHub repository or any remote you already trust. Until then, nothing is uploaded.

AI

No AI until you add one.

The AI agent does nothing until you add your own Anthropic, OpenAI, or OpenRouter key, and then talks to that provider directly. External agents stay off until you turn them on, and see only the vaults you tick.

Your choice

Every way out is one you turn on.

  • SyncCommits, to the Git remote you add
  • AI agentTo the provider whose key you add
  • External agentsOnly the vaults you allow
  • PublishingOne note and its images, when you click Publish
  • FeedbackApp version and OS. Never your notes
  • AnalyticsNone. No account needed

Where your notes go

AI agents

Speaks agent, natively.

Your notes are already in the format language models read best. When you turn it on, Claude, Codex, and other agents can work in the vaults you pick, through MCP, while you stay in charge.

Markdown

No integration needed.

Every note is a plain .md file. Point any agent at the folder and it reads, searches, and edits your notes the way it works with code.

~/Field Notes $ grep -l "#cairo" *.md

Old streets.md

Approval

You decide what waits for you.

Pick which vaults each agent can reach and how it edits them. Every accepted change is committed as Agent: …, so it lands in history like any other edit.
